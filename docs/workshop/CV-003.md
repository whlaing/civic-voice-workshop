# CV-003: Add feedback character count and limit

Scope: live character count and a 500-character maximum in the citizen form.

Verification: typing, deletion, paste, 500-character submission, counter reset, npm test, and npm run build.

Status: implemented and verified. API changes are out of scope.

Results:

- All 18 tests pass, including six component-handler regression tests.
- Production build and git diff whitespace checks pass.
- Browser: typing and deletion update the counter; extra typing at 500 is blocked.
- Browser: pasting 520 characters retains 500; submitting succeeds and resets the counter to zero.

The count uses JavaScript string length (UTF-16 units), matching the browser's maxlength behavior. Some emoji use two units. This is a form-only limit, not server-side validation.

No dependencies or API behavior were changed for this ticket.
